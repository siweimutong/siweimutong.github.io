Projects 项目

Selected research projects. 部分研究项目

ROS-RTEMS

Integrates ROS 2 with the RTEMS real-time operating system to provide native, deterministic real-time execution for robotic applications.将 ROS 2 与 RTEMS 实时操作系统集成，为机器人应用提供原生、确定性的实时执行能力。

Dual-Kernel Xenomai for Raspberry Pi 5面向 Raspberry Pi 5 的双内核 Xenomai 研究

Develops a dual-kernel real-time architecture based on Xenomai for deterministic execution on Raspberry Pi 5.构建基于 Xenomai 的双内核实时架构，在 Raspberry Pi 5 上实现确定性执行。

Heterogeneous Autonomous Driving Real-Time Performance异构自动驾驶实时性能研究

Studies timing analysis and scheduling of computation and communication for real-time performance in heterogeneous autonomous driving systems.研究异构自动驾驶系统中计算与通信的时序分析与调度，保障系统的实时性能。

Satellite-VNF-Placement

Provides a reinforcement-learning solution for VNF task placement in satellite environments.提出基于强化学习的卫星环境 VNF 任务放置方案。
